# UIとキャラJSONの見直し — 2026-10-22

## 目的

夢小説を書きたい人が、迷わず・気分よく「推しを選ぶ → 回す → コピー」できるようにする。あわせて、作品別キャラJSONを人が編集しやすい形に整理する。

## UIの変更

| 課題 | 変更 |
| --- | --- |
| 「アーカイブ」が、小説の保存先（下部メニュー）とキャラをガチャから外す操作の2つの意味で使われていた | 小説・条件の保存先を **本棚**、キャラをガチャから外す状態を **お休み**（戻す操作は「ガチャに戻す」）に統一 |
| 1303人中1024人が初期状態でガチャ対象外。推しをガチャに出すには一覧から探して1人ずつ「復元」する必要があった | キャラ管理に **作品** タブを追加。作品ごとに「出ている人数／全体」をバーで表示し、開いてキャラをタップするだけで出す／お休みを切り替え。部・シリーズの小見出し、「全員出す」「全員お休み」「★だけ出す」付き |
| キャラ選択画面がデータの登録順で、作品が混在していた | お気に入りを先頭に、残りを作品ごとの見出しで並べる。見つからないときは「作品」タブへの案内を表示 |
| 管理一覧のキャラカードがタグの数だけ縦に伸びた | タグは5個まで表示し、残りは「+N」にまとめる |
| ガチャを回しても結果の変化が分かりにくかった | 引いた項目だけがふわっと表示し直され、キャラ枠が一瞬光る。サイコロアイコンが回る。端末の「視差効果を減らす」設定では動かない |
| キャラ枠が単色 | 淡いグラデーションと小さな ✦ を追加 |

保存キー、localStorage・IndexedDBの形式、バックアップ形式、プロンプト本文は変更していない。`archived` などのデータ項目名もそのままで、表示名だけを変えた。

## キャラJSONの変更

`data/characters/*.json` を `version: 2`（作品ファイル形式）へ変換した。

- 作品名はファイル先頭の `work` に1回だけ書く（以前は全キャラに重複）。
- 1キャラ1行。差分が見やすく、メモ帳でも検索しやすい。
- 身長は `"height": 180` のように書ける。確認状態と出典はファイル先頭の `heightDefaults` にまとめ、異なるキャラだけ個別に書く。身長不明は省略。
- ガチャ対象外は `"gacha": false`。`favorite` は端末ごとの設定なので作品ファイルには書かない。
- ファイルをまたいだ全体の並び順 `sourceOrder` を廃止し、ファイル名順・ファイル内の順をそのまま並び順にした。
- 書き間違えた項目名（`tag` など）や、キャラ側に `work` を書いた場合は日本語のエラーで知らせる。

合計サイズは約770KBから約294KBになった。変換処理は `src/character-format.js` にまとめ、データ生成ツールとアプリの「JSONを読み込む」が同じ処理を使う。以前の `version: 1` も引き続き読み込める。ChatGPT用の依頼文・テンプレート・使い方ページの例も新形式に更新した。

`node tools/build-character-data.js --format` で全ファイルを標準の書式へ整え直せる（`version: 1` の変換もこのコマンド）。

### 内容が変わっていないことの確認

変換前後の `data/character-data.generated.js` をIDごとに比較し、1303人全員の全項目が一致した。変わったのは並び順だけで、既存の利用者は保存済みの一覧の順序を使うため影響しない。新規利用者の「登録順」は作品ごとにまとまった順になる。
