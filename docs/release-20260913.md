# v0.33 更新・検証記録

日付：2026-09-13。既存のガチャを入口に、任意カルテと編集可能な条件セットを追加した。

## 変更

- キャラ管理・ガチャ結果から、一つの自由文だけでもカルテを登録できる。お気に入り登録とカルテの入力は必須ではない。
- 既存の補足設定を使い、共通・原作世界・特定AUの適用範囲、原作情報・個人の解釈・AU創作・未分類の出所を分ける。原作根拠や確認状態も任意の操作で記録できる。
- ガチャ・手動選択・直接編集・過去セットの再利用は同じ条件を扱う。補助シチュと関係性の入力補助を追加した。
- 今回用の夢主設定を標準設定から分け、保存条件を開いても標準を書き換えない。
- 条件が変わっても完成文を保持し、古い文を新条件の生成記録へ混ぜない。手編集の自動置換を防ぎ、表示文をそのままコピーする操作を設けた。
- 条件セットを同じIDのまま更新できる。カルテが参照するキャラIDを読込・作品更新時に保護し、未登録キャラのカルテも確認・紐付け直しできる。
- 全機能の確認で、削除した初期キャラが再読込で復活する問題を再現・修正。初期キャラの現在のID、および名前・作品で照合される旧IDにも削除記録を残す。カルテと保存条件は削除しない。

## 互換性

設定45、完全バックアップ4。完全バックアップ1〜3を読み込める。カルテを含む新しい補足snapshotは2、含まない場合は従来の1。既存の個人の固定文・小説・過去の生成時記録を書き換えない。

小説JSONはカルテを含む場合のみ `dream-gacha.novel-export` v2、`contextScope: applied-only` とし、適用した設定だけを書き出す。完全バックアップには未使用のカルテも含める。従来のキャラJSONにはカルテを含めない。

固定プロンプト0.1.3.3、配布キャラデータ、コピーして外部AIを使う方式は維持。API・自動査読・アノテーターの完全統合は追加していない。
