# ミニマルUI改修 — 2026-10-25

## 目的

画面の拡大縮小を止める。説明文や重複したラベルを減らし、配置とアイコンで操作が分かる画面にする。

## 拡大縮小の無効化

- `viewport` に `maximum-scale=1, user-scalable=no` を追加。
- `html{touch-action:pan-x pan-y}` でピンチとダブルタップの拡大を止め、縦横のスクロールは残す。
- iOS Safari は `user-scalable=no` を無視するため、`gesturestart` などのジェスチャーイベントを取り消す（`src/app-experience.js` の `lockZoom`）。
- PCのトラックパッドのピンチ（Ctrl＋ホイール）と、Ctrl／⌘＋`+` `-` `0` も取り消す。
- 入力欄は従来どおり16px。フォーカス時の自動拡大も起きない。

2026-10-16のスマホUI改修では「ページの拡大は妨げない」としていたが、所有者の依頼で方針を変更した。

## 画面の変更

| 場所 | 変更 |
| --- | --- |
| 共通 | ヘッダーの「使い方」を削除（下部メニューと重複）。下部メニューは「ガチャ・本棚・キャラ・設定」。フッターのバージョン表記は設定画面へ移動 |
| ガチャ | 「簡単モード／カスタマイズ」を「シンプル／カスタム」にしてヘッダー右へ移動。「今回の組み合わせ」見出しと外枠を削除 |
| キャラ欄 | 名前そのものを「選ぶ」ボタンにし（▼で示す）、「キャラ」ラベルと「キャラを選ぶ」を削除。固定は鍵アイコン、お気に入りは☆ |
| 結果の行 | 左に項目名、右に内容。カスタムでは項目名の行に「引き直す・候補から選ぶ・固定」のアイコン。シンプルでは固定中の行だけ鍵を表示 |
| 結果の詳細 | 「選ぶ・カテゴリ」の折りたたみを削除。カテゴリは候補選択画面にあり、指定中のときだけ行に表示 |
| 絞り込み | 世界観・検索・身長・タグ・候補キャラの説明文を削除。お気に入りは検索欄横の★ |
| 条件編集・設定 | 各所の説明文を削除し、ラベルを短縮（例：「今回だけの追加指定（任意）」→「追加指定」） |
| 本棚 | タブを「小説／条件／＋ 小説」に。見出しの重複、入力欄の説明文を削除。AIとモデルを横並び。お気に入りは☆ |
| キャラ管理 | 4つの統計と状態ボタンを、件数付きの絞り込みタイル（全員・ガチャ・お休み・★）に統合。一覧の行は名前と「作品 / 部 / 身長」の1行に。お休み中は薄く表示 |
| 設定 | 「はじめての使い方」「基本の流れ」「各ページの詳細」を削除。表示設定・バックアップ・ChatGPTでキャラを作る・よくある質問の順。JSON形式と使えるタグは折りたたみ |

要素のIDは変更していない（削除は使い方ページの `help-basic`・`help-details` のみ）。保存キー、localStorage・IndexedDBの形式、バックアップ形式、プロンプト本文は変更していない。読み上げ用に、アイコンのボタンには `aria-label` を付けた。
