ChatGPTでキャラを作る

回答はJSONファイルとして保存し、キャラ管理 → ファイルから読み込みます。人数・名前・身長は読み込む前に確認してください。

JSONの形式 
{
  "schema": "dream-gacha.characters",
  "version": 2,
  "work": "作品名",
  "heightDefaults": { "status": "verified", "source": "出典名またはURL" },
  "characters": [
    { "name": "キャラ名", "series": "部・シリーズ", "tags": ["冷静", "知的"], "height": 180 },
    { "name": "身長不明のキャラ", "tags": ["明るい"] },
    { "name": "ガチャから外すキャラ", "tags": ["寡黙"], "gacha": false }
  ]
}
  • 1ファイル1作品。作品名は work に1回だけ書きます。
  • 身長は "height": 180。分からなければ省略します。
  • 媒体で違うときは { "cm": 180, "text": "180cm（アニメ）／178cm（原作）" }。
  • "gacha": false は「お休み」で読み込まれます。
  • 以前の形式（version 1）も読み込めます。

よくある質問

お気に入りとお休みの違いは？

お気に入りは好きなキャラに付ける印です。お休みはキャラを消さずにガチャに出さない状態です。

お休みにしたキャラは消えますか？

消えません。キャラ管理の「作品」でタップするか、一覧の「お休み」で絞り込んで「ガチャに戻す」を押すと戻せます。

カテゴリの選択と除外の違いは？

カテゴリ名を押すとそのカテゴリだけが候補になります。「除外」はそのカテゴリを外し、複数同時に使えます。

候補キャラの選択と除外は？

押したキャラはまとめて抽選対象になります。「除外」またはPCの右クリックで対象から外せます。

鍵のマークは？

鍵をかけた項目は、次にガチャを回しても変わりません。

夢主設定はどこに入りますか？

カスタムの「夢主・候補・プロンプト」で書きます。プロンプトには固定プロンプトとは別に入ります。作品別の設定は、その作品のキャラが選ばれたときだけ追加されます。

世界観で何が変わりますか？

原作準拠では電車・スマホ・コンビニなど現代専用のシチュを外します。現代パロ・学園パロはそれぞれの候補と共通の候補を、制限なしはすべてを使います。

データは外部に送信されますか？

されません。保存先はこのブラウザ内だけです。

別の端末で続きを使うには？

上の「完全バックアップを書き出す」で保存し、移動先で「復元」してください。

1作品のキャラだけ更新できますか？

キャラ管理 → ファイルで「作品単位で置換」を選び、1作品だけのJSONを読み込みます。ほかの作品とお気に入り・お休み状態は残ります。
