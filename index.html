まずはこの4ステップ

キャラの好みを整える

好きなキャラは「★ お気に入り」へ。苦手なキャラや今は出したくないキャラは「アーカイブ」へ移します。

CHATGPT + JSON

ChatGPTでキャラファイルを作る

作品単位でまとめて追加

作品名を入力して依頼文をコピーし、ChatGPTへ送ります。返ってきたJSONをファイルとして保存したら、キャラ管理の「JSONを読み込む」から追加できます。

  1. 作品名を入力正式な作品名を入力します。
  2. 依頼文をコピー男性キャラの調査条件・JSON形式・許可タグがまとめて入ります。
  3. JSONで保存ChatGPTの回答を説明文なしの .json ファイルとして保存します。
  4. 追加・更新で読み込む最初は既存キャラを残せる「追加・更新」がおすすめです。

JSONの基本形式

{
  "schema": "dream-gacha.characters",
  "version": 1,
  "characters": [
    {
      "name": "キャラクター名",
      "work": "作品名",
      "series": "部・シリーズ",
      "tags": ["冷静", "知的"],
      "archived": false,
      "favorite": false,
      "heightText": "180cm",
      "heightCm": 180,
      "heightStatus": "verified",
      "heightSource": "出典名またはURL"
    }
  ]
}

身長を調べるときのルール

  • 公式サイト、公式プロフィール、出版社・制作会社の資料を優先します。
  • 複数の公式値がある場合は heightText に併記し、代表値を heightCm に入れます。
  • 公称値が見つからなければ推測せず、heightText は「不明」、heightCm は null にします。
  • 確認できた場合は heightStatus を verified、不明なら unknown にします。

読み込む前に確認

ChatGPTの調査結果には誤りが含まれる場合があります。人数、名前、部・シリーズ、身長と出典を確認してから読み込んでください。「ファイル内容で全キャラ置換」は現在の一覧を置き換えるため、通常は「追加・更新」を使います。

データの保存と引っ越し

大切な作品を守るために

キャラ・設定・保存した小説は、このサイトを開いているブラウザ内に保存されます。別の端末やブラウザには自動で移りません。

ブラウザのデータを消す前や端末を替える前に、キャラ管理の「完全バックアップ」を書き出してください。 新しい環境でそのファイルを復元すると、まとめて引き継げます。

よくある質問

FAQ
お気に入りとアーカイブはどう違いますか？

お気に入りは、好きなキャラだけに絞り込むための印です。アーカイブはキャラを消さずにガチャ対象から外す機能です。

アーカイブしたキャラは消えますか？

消えません。キャラ管理の「📦 アーカイブ」で絞り込み、対象を選んで「復元」を押すとガチャ対象に戻せます。

「カテゴリを選ぶ」と「除外」の違いは？

カテゴリ名を選ぶと、その1カテゴリだけを候補にします。「除外」は指定したカテゴリを候補から外し、複数同時に設定できます。

ガチャ結果の「固定」とは？

固定した項目は「固定以外を全部ガチャ」を押しても残ります。画面上の「固定を全解除」でまとめて戻せます。

夢主設定はどこに入りますか？

ガチャ画面下部の設定欄に入力します。「プロンプトを生成」したとき、固定プロンプトとは別の「夢主設定」として自動で入ります。

保存した小説や設定は外部に送信されますか？

このサイトの保存機能はブラウザ内を使います。サイト側のサーバーへ作品を保存する仕組みはありません。

別のスマホやパソコンでも続きから使えますか？

キャラ管理で完全バックアップを書き出し、移動先のブラウザで復元してください。
