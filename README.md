# 夢小説シチュガチャ

フォルダー一式を同じ場所に置き、`index.html` をダブルクリックして利用できます。

設定はブラウザーの localStorage、夢小説は IndexedDB に保存されます。完全バックアップは両方を一つの JSON に書き出し、どちらかの読み出しに失敗した場合はファイルを作りません。復元前に全内容を検証し、設定または夢小説の書き込みで通常のエラーを検出した場合は復元前のデータへ戻します。ブラウザー自体の強制終了など、二つの保存領域をまたぐ処理を中断された場合まで一括保証するものではありません。

旧形式（完全バックアップ version 1）に `novels` が含まれない場合、現在の夢小説アーカイブを維持します。新形式で `novels: []` が明示されている場合は、アーカイブを空にします。

## テスト

Node.js 18 以降で `node --test` を実行します。
