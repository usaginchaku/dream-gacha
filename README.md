# 夢小説シチュガチャ

フォルダー一式を同じ場所に置き、`index.html` をダブルクリックして利用できます。

ガチャでは「原作準拠・現代パロ・学園パロ・制限なし」から世界観を選べます。原作準拠では、電車・スマートフォン・コンビニなどを前提とするシチュエーションを自動で候補から外します。夢主設定は共通設定に加えて作品別にも編集でき、完成プロンプトには選択キャラの作品に対応する設定だけが追加されます。「自由な追加指定」は今回のプロンプトだけに加わります。

## 固定プロンプト

標準の固定プロンプトは **Ver.0.1.3.2** です。全文は [`prompts/dream-novel-0.1.3.2.md`](prompts/dream-novel-0.1.3.2.md) に保存し、ファイルをダブルクリックして使えるよう `seed-data.js` にも同じ文面を収録しています。テストで両者の一致を確認します。

旧標準文と一致する設定は起動時に新版へ更新します。独自に編集した固定プロンプト、保存条件、生成済みプロンプトの履歴、保存済み小説は今回の更新で書き換えません。

## キャラデータの更新

作品別の初期キャラデータは `data/characters/` にあります。JSONはアプリのキャラ入出力と同じ `schema: "dream-gacha.characters"`、`version: 1`、`characters` 配列の形式です。作品を追加するときは、同じ形式のJSONをこのフォルダーへ追加し、各キャラに重複しない `id`、`name`、`work` を指定してください。タグはアプリに表示される共通タグだけを使い、身長不明は `heightCm: null`、`heightStatus: "unknown"` とします。

Node.js 18以降が入っているWindowsでは `キャラデータを更新.bat` をダブルクリックすると、JSONを検証して `character-data.generated.js` を生成できます。コマンドラインでは `node tools/build-character-data.js` を実行します。JSON構文、schema/version、必須項目、ID重複、同じ作品の同名重複、許可外タグ、身長4項目（表示・数値・状態・出典）の整合性を検査します。失敗した場合は内容を確認してJSONを修正してから再実行してください。

`character-data.generated.js` は公開用の生成ファイルです。直接編集せず、作品別JSONを更新してからビルドしてください。`index.html` はこの生成ファイルを `seed-data.js` より先に読み込むため、ファイルをダブルクリックする従来の起動方法もそのまま使えます。

設定はブラウザーの localStorage、夢小説は IndexedDB に保存されます。完全バックアップは両方を一つの JSON に書き出し、どちらかの読み出しに失敗した場合はファイルを作りません。復元前に全内容を検証し、設定または夢小説の書き込みで通常のエラーを検出した場合は復元前のデータへ戻します。ブラウザー自体の強制終了など、二つの保存領域をまたぐ処理を中断された場合まで一括保証するものではありません。

画面からキャラJSONを更新するときは「作品単位で置換」が通常の導線です。JSONに含まれる1作品だけを入れ替え、ほかの作品と、同じキャラのお気に入り・アーカイブ・手動入力した身長を維持します。全キャラ置換は「高度な操作」にあります。

作品名と部・シリーズは複数選択と除外を併用できます。パソコンでは左クリックで選択、右クリックで除外します。スマートフォンではパネル内の「選択」「除外」を切り替えてから項目を押します。

旧形式（完全バックアップ version 1）に `novels` が含まれない場合、現在の夢小説アーカイブを維持します。新形式で `novels: []` が明示されている場合は、アーカイブを空にします。
